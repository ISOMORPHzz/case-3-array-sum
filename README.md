# case-3-array-sum
Найти сумму отрицательных элементов

| Параметр         | Значение                                          |
| ---------------- | ------------------------------------------------- |
| Входные данные   | Одномерный массив A размерности N                 |
| Выходные данные  | Сумма отрицательных элементов                     |
| Область поиска   | Элементы, расположенные между позициями max и min |

Ключевой вопрос интерпретации: «между» — включающие или исключающие сами граничные элементы? Поскольку max ≥ 0 (или хотя бы не отрицательный, если все элементы отрицательны), а min ≤ 0, включение граничных элементов исказило бы результат. Принято решение: границы не включаются (строгое «между»).
Этап 2. Разработка алгоритма

    Найти индекс max_idx максимального элемента — O(N).
    Найти индекс min_idx минимального элемента — O(N).
    Определить левую и правую границы диапазона: left = min(max_idx, min_idx) + 1, right = max(max_idx, min_idx).
    Пройтись по срезу arr[left:right] и просуммировать элементы, меньшие нуля.
    Вернуть сумму (или 0, если отрицательных нет).

Сложность: O(N) по времени, O(N) по памяти (для среза). Можно оптимизировать до O(1) по памяти, если итерироваться по индексам без создания среза.
Этап 3. Реализация

    Выбран язык Python 3.10+ — лаконичный синтаксис, встроенные функции max(), min(), index(), генераторные выражения.
    Код разделён на модуль с логикой (array_sum.py) и точку входа (main.py) — принцип разделения ответственности.
    Добавлена обработка граничных случаев: пустой массив, отсутствие отрицательных элементов, смежные min/max.

Написан набор unit-тестов (unittest), покрывающих:

    ✅ Базовый случай (min после max).
    ✅ Обратный порядок (min перед max).
    ✅ Отсутствие отрицательных элементов между границами.
    ✅ Смежные min и max (между ними нет элементов).
    ✅ Массив из одних отрицательных чисел.
    ✅ Пустой массив (ошибка ValueError).

📊 Пример работы
Вход: [3, -2, 7, -5, 1, -8, 4, -1, 6]
      
| Шаг         | Действие     | Результат                          |
| ---------------- | ------- | ---------------------------------  |
| 1   | Находим max               | 7 (индекс 2)                  |
| 2   | Находим min               | -8 (индекс 5)                 |
| 3   | Диапазон «между»          | индексы 3, 4 → элементы -5, 1 |
| 4   | Отрицательные в диапазоне | -5                            |
| 5   | Сумма                     | -5                            |
